products. The site highlights full-stack breadth across frontend, backend,
APIs, payments, deployment, and AI integrations.

## Live site

The portfolio is designed to be deployed as a static site on GitHub Pages,
Vercel, Netlify, S3, or any other static host.

## Run locally

This is a static website with no build step or package manager required.

1. Clone the repository.
2. Open `index.html` directly in a browser, or serve the folder with any local static server.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Design direction

The visual system uses Space Grotesk for headings, IBM Plex Sans for body
text, and IBM Plex Mono for labels and tags. It uses a warm off-white canvas,
near-black typography, restrained blue accents, hairline borders, and a
left-aligned asymmetric layout.
